# Contributing

Спасибо за интерес к ChuddoEngine! Пожалуйста, следуйте этим правилам при внесении изменений.

1. Форк, создайте ветку и отправьте Pull Request.
2. Пишите понятные сообщения коммитов.
3. Добавляйте тесты, если меняете поведение подсистемы коллизий.
4. Соглашение по коду: стиль должен быть согласован с существующим кодом (CamelCase для классов, метод names как `GetActorLocation`).
